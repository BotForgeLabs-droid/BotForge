## 📌 About BotForge

**BotForge** (formerly BotBazzar) is an open-source web application designed to help small businesses integrate customizable AI chatbots into their online presence. It provides a polished landing page with interactive demonstration features, pricing tiers, contact inquiry forms, and responsive design.

### 🌐 Live Demo
Experience the live application here: **[https://bot-bazzar.netlify.app/](https://bot-bazzar.netlify.app/)**

---

## ✨ Features

- **⚡ Animated Hero Section**: Engaging landing view with modern gradient typography and call-to-action triggers.
- **🤖 Interactive Chatbot Demo**: Real-time simulated chatbot interface showcasing business communication capabilities.
- **📊 Dynamic Pricing Options**: Clear pricing tier breakdown tailored for scaling businesses.
- **📝 Lead Contact Form**: Interactive contact and onboarding inquiry form.
- **📱 Fully Responsive**: Optimized for desktop, tablet, and mobile displays.

---

## 🛠️ Technology Stack

- **Frontend Core**: React 18 & TypeScript 5
- **Build System & Dev Server**: Vite 5
- **Styling**: Tailwind CSS 3 & PostCSS
- **Iconography**: Lucide React
- **Modular Utilities**: Vanilla JavaScript scripts (`scripts/`)
- **Backend Client**: Supabase Client (`@supabase/supabase-js`)

## 🚀 Getting Started

Follow these steps to run BotForge locally on your computer:

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher recommended) installed.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/BotForgeLabs-droid/BotForge.git
   cd BotForge
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173` (or the URL printed in terminal).

4. **Build for production**:
   ```bash
   npm run build
   ```
